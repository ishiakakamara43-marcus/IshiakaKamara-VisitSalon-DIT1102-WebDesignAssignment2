# VISITSALONE

**VISITSALONE (Visit Salone)** is a website project focused on showcasing Sierra Leone's destinations, culture, nature, and travel experiences.

## Project overview

The current source files provide:

- **Home page (`index.html`)** — introduces Visit Salone and highlights selected destinations.
- **Destinations page (`destinations.html`)** — displays destination cards for Freetown, Turtle Islands, Bonthe, Kamberi Hills, Tacugama, and Sumbuya.
- Responsive viewport metadata, semantic HTML elements, accessible labels, and descriptive image alt text.

## Built with

- HTML5
- CSS3 (stylesheet is referenced as `css/style.css`)
- JavaScript (script is referenced as `js/script.js`)

## Run locally

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Add the missing `css/style.css` and `js/script.js` files.
4. Open `index.html` in a browser, or use the **Live Server** extension in VS Code.
5. Open `destinations.html` to view the destinations page.

No package installation or build command is required for the supplied HTML files.
