# IshiakaKamara-VisitSalon-DIT1102-WebDesignAssignment2
VISITSALONE is a tourism and travel discovery website dedicated to showcasing the beauty, diversity, and cultural richness of Sierra Leone. The platform highlights some of the country's most attractive destinations, including Freetown, Turtle Islands, Bonthe, Kamberi Hills, Tacugama, and Sumbuya.

The website is designed to help visitors explore Sierra Leone's natural landscapes, historical locations, wildlife, cultural attractions, and unique travel experiences. It provides an engaging online platform where users can discover interesting places, learn about destinations, and connect with the country's tourism potential.

Built using HTML5, CSS3, and JavaScript, VISITSALONE focuses on creating an attractive, user-friendly, and responsive browsing experience. The project aims to promote Sierra Leone as a beautiful travel destination while demonstrating practical front-end web development skills.

**Project Goal:** To make discovering and exploring Sierra Leone easier through a modern digital tourism platform.

**Technologies:** HTML5 | CSS3 | JavaScript
